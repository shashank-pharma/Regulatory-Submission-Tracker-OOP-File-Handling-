# Regulatory-Submission-Tracker-OOP-File-Handling-
This project is a simple Python-based Regulatory Submission Tracking System built using Object-Oriented Programming (OOP) and File Handling concepts.

A simple Python-based Regulatory Submission Tracking System built using Object-Oriented Programming (OOP) and File Handling.

## Features
- Create and manage regulatory submissions
- Store submission records in a text file
- Filter approved submissions
- Use OOP concepts like classes, objects, methods, and validation logic

## Technologies Used
- Python
- OOP
- File Handling

## Concepts Practiced
- `__init__()`
- `__str__()`
- Object lists
- File append/read modes
- Validation methods
